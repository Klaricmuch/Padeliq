# Padeliq

Landing page for PadelIQ — AI video analysis for padel. Upload one clip from a single camera and get the ball tracked in real time: bounces, shot speed, rally tempo, and the read a coach would give you.

## Contents

- `index.html` — the full landing page (self-contained: HTML, CSS, and JS in one file, including the animated hero court demo).

## Run locally

It's a single static file, so any of these work:

```bash
# Python
python3 -m http.server 4599
# then open http://localhost:4599

# or just open the file directly
open index.html
```
